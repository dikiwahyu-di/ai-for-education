# AI Learning Experiments

This directory documents practical experiments exploring the application of Generative AI in educational settings.

## Experiment 01: AI-Assisted Lesson Planning

### Research Question

How effectively can Generative AI support the development of pedagogically aligned lesson plans?

### Experimental Context

- Subject: Informatics
- Grade: 8
- Topic: Computational Thinking
- Duration: 80 minutes
- Framework: ADDIE
- Learning Taxonomy: Revised Bloom's Taxonomy

### Method

1. Develop a structured instructional design prompt.
2. Submit the prompt to a Generative AI model.
3. Analyze the generated lesson plan.
4. Evaluate instructional alignment.
5. Identify strengths and limitations.

### Evaluation Criteria

| Criterion | Evaluation Focus |
|---|---|
| Learning Objectives | Measurability and clarity |
| Instructional Alignment | Alignment between objectives and activities |
| Pedagogical Quality | Appropriateness of learning strategies |
| Assessment Design | Alignment with learning outcomes |
| Practicality | Feasibility in classroom settings |

### Results

To be completed after conducting the experiment.

### Limitations

AI-generated instructional materials require human review, contextual adaptation, and pedagogical validation.
