# AI Prompt Library for Teachers

A collection of practical Generative AI prompts designed to support teachers in designing meaningful learning experiences.

## Purpose

This project explores how prompt engineering can help educators improve productivity, creativity, and instructional quality.

## Prompt Categories

### 1. Lesson Planning
Prompts for designing lesson plans, learning objectives, and instructional activities.

### 2. Assessment Design
Prompts for developing quizzes, formative assessments, and evaluation rubrics.

### 3. Learning Media
Prompts for creating engaging digital learning materials and multimedia content.

### 4. Gamification
Prompts for designing game-based learning activities and classroom challenges.

## Design Principles

Every prompt should consider:

- Learning objectives
- Student characteristics
- Subject matter
- Learning activities
- Assessment strategies
- Expected learning outcomes

## Project Status

Currently under development.

More prompts, examples, and practical experiments will be added continuously.
