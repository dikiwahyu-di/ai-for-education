# AI-Assisted Lesson Planning

## Project Overview

This project explores the use of Generative AI to support teachers in designing structured, meaningful, and student-centered lesson plans.

The prompt integrates instructional design principles, ADDIE methodology, and Bloom's Taxonomy.

## Learning Objectives

This prompt aims to help teachers:

- Develop measurable learning objectives.
- Design student-centered learning activities.
- Align instructional strategies with Bloom's Taxonomy.
- Integrate appropriate educational technology.
- Design assessments aligned with learning outcomes.

## Master Prompt

You are an experienced instructional designer and educational technology specialist.

Help me design a comprehensive lesson plan based on the following information:

**INPUT INFORMATION**

- Subject: [Insert subject]
- Grade level: [Insert grade]
- Topic: [Insert topic]
- Learning duration: [Insert duration]
- Student characteristics: [Describe students]
- Learning environment: [Classroom / Online / Hybrid]

**INSTRUCTIONS**

1. Analyze the learning needs and student characteristics.
2. Formulate measurable learning objectives using Bloom's Taxonomy.
3. Design learning activities based on the ADDIE instructional design framework.
4. Recommend suitable teaching methods and digital learning tools.
5. Develop assessment strategies aligned with the learning objectives.
6. Include differentiation strategies for diverse student needs.
7. Provide suggestions for improving student engagement.

**EXPECTED OUTPUT**

Organize the lesson plan into:

1. Learning context and needs analysis.
2. Learning objectives.
3. Learning materials.
4. Teaching and learning activities.
5. Instructional media and technology.
6. Assessment and evaluation.
7. Learning reflection.

Use clear, structured, and professional language.

Ensure that all proposed activities are realistic, pedagogically appropriate, and adaptable to the classroom context.

## Educational Design Principles

- Student-centered learning.
- Constructive alignment.
- Bloom's Taxonomy.
- ADDIE instructional design.
- Technology-enhanced learning.
